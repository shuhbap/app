# Zolvex Studio (Phase 1)
Android-only design studio. Kotlin, Jetpack Compose, Material 3. Package: com.zolvex.studio

Open in Android Studio (Koala or newer, JDK 17), let Gradle sync, press Run.
Debug APK: Build > Build APK(s). Release: Build > Generate Signed Bundle / APK.
Templates are layer-based data (see data/model/Template.kt), never flat images.
